**Solution:** Production multi-agent orchestration (specialized agents for inventory, job scheduling, accounts receivable, operational risk) with mandatory human approval gates before any action. ### agentplayground
**Problem:** Quantitative researchers and systematic traders need transparent, auditable AI assistance — not black-box predictions — for signal research, risk analysis, and trade proposals.  
**Solution:** Agentic hedge-fund research copilot and market intelligence platform. Multi-agent system (LangGraph) with real-time market data, news/filings interpretation, multi-factor risk modeling, paper trading, and explicit human-in-the-loop approval gates. Full reasoning traces.  
**Impact:** Designed for high-stakes domains where auditability and human oversight are non-negotiable. Local-first research platform with continuous learning from outcomes.  
`Python` `LangGraph` `Fintech` `Quantitative Finance` `Human-in-the-Loop`

### local-adversarial-agent
**Problem:** Most AI security tooling depends on cloud APIs and opaque datasets, making creative red team research and education difficult to run privately or deterministically.  
**Solution:** Fully local Red Team vs Blue Team AI simulation arena using Ollama + LangGraph. Creative adversarial agents with narrative personas that mechanically impact stealth and success rates. Robust state machine with checkpointing/replay, human annotation, and dataset export.  
**Impact:** 100% local/offline, reproducible network simulator, educational + research value for cybersecurity and agentic experimentation.  
`Python` `LangGraph` `Ollama` `Cybersecurity` `Red Team` `Simulation`

### agentville
**Problem:** Testing multi-agent coordination and emergent behaviors usually requires expensive staging environments and manual validation that slows iteration.  
**Solution:** Local simulation environment with a full Windows 95 retro desktop shell (draggable windows, CRT scanlines, Pixi.js sprites). Built to validate coordination patterns before production deployment. Live demo available.  
**Impact:** High-signal portfolio piece demonstrating orchestration + usable interfaces. Retro aesthetics make complex agent state and coordination visually testable and engaging.  
`TypeScript` `Next.js` `Pixi.js` `Framer Motion` `Agent Simulation` `UI/UX`

### psyop-threat-gauge
**Problem:** Coordinated inauthentic behavior (financial rumor swarms, information operations) moves faster than manual monitoring or simple heuristics can handle.  
**Solution:** OpenClaw-native multi-agent defensive system. Spawns realistic rumor-propagation agent swarms (Originator, Amplifier, Skeptic, Opportunist), feeds them into a fusion/scoring engine with exact Artificiality Score, and triggers human-in-the-loop review on high-score clusters. Local-first with Ollama fallback.  
**Impact:** Production-grade defensive orchestration patterns with graceful degradation, robust CLI discovery, and ethical safeguards (simulation-only, human review required).  
`Python` `OpenClaw` `Multi-Agent` `Threat Detection` `Local AI`

### storyteller
**Problem:** Generic LLM outputs lack the structure, consistency, and schema compliance required for reliable production agent workflows.  
**Solution:** SLM-powered structured generation pipeline with strict schema enforcement and controllable outputs. Designed as a foundational component for agent systems that must produce machine-readable, validated artifacts.  
**Impact:** Demonstrates  the difference between brittle free-form generation and production-ready structured output. Core building block for accountable agent architectures.  
`Python` `SLM` `Structured Generation` `Schema Enforcement`
